# Product import by URL

Workspace owners can use Products → Import from website, paste a public HTTPS product-details URL, Fetch product, then Review in product form. Techland category URLs also support the current page’s listing cards (up to 20); prices come from the displayed selling-price element, not crossed-out prices or savings. Product names, short specification bullets, photos and individual source URLs are extracted. Pagination and automatic bulk save are not performed.

The page supports Schema.org Product JSON-LD (including arrays, @graph, item lists and product variants nested in the document) and Open Graph product metadata. Up to 20 records from the single page are offered for selection. The existing editable form handles the final Save through tenant-scoped product RLS.

Name, description, SKU, category, explicit offer price/currency, explicit numeric inventory and an optional photo are copied. InStock is never converted to an invented quantity. Unknown price, currency and stock remain blank and require review/input. AggregateOffer price ranges are not treated as a specific variant's price. Image fetch failure leaves the text import usable with manual photo upload. Images are MIME/signature checked and copied into the existing private product-image bucket only on Save. Previewing does not create product rows or storage objects. Existing SKU uniqueness rejects accidental duplicates with the same SKU; products without SKU require the owner's review to avoid duplicates.

The route authenticates the single workspace owner before fetching. Server HTTPS requests send no app credentials, cookies or user Authorization header to external websites. DNS IPv4 addresses must be public and are pinned to the TLS request; every redirect is revalidated. IP literals, local hosts, credentials, non-HTTPS URLs and custom ports are rejected. There are at most three redirects, a shared 12-second timeout, HTML/image content-type restrictions, image magic-byte validation and bounded response sizes. HTML and JSON-LD are parsed as data; scripts are never executed.

This is a one-time, single-page import, not a full-site crawler, inventory sync, login bypass or JavaScript browser renderer. Unsupported/blocked/JavaScript-only pages show a clear error and can be entered manually. Administrators can still edit products; URL importing currently uses the owner authorization path shared with channel setup.

Validation: 38 automated tests including parser fixtures, zero price, unknown stock, malformed JSON-LD, metadata fallback, private-IP rejection, pinned DNS and redirect validation; Next.js production build/typecheck. A real outbound HTTPS smoke check in the local execution environment was blocked by DNS ECONNREFUSED. Techland desktop RAM category HTML was fetched successfully (HTTP 200), and parsing produced 20 products; the first two displayed selling prices and image URLs were checked. Owner-authenticated Save and image download still need verification in the dashboard.
